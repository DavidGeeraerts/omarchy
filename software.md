Package installs are skipped when the package is already installed. `zulu-21-bin` is the AUR package: the scripts call `omarchy pkg aur add zulu-21-bin` and skip that when `pacman -Q zulu-21-bin` already succeeds. Schwab requires Zulu OpenJDK 21, not JDK 25. When `archlinux-java` is available, the scripts set the Zulu 21 environment from `archlinux-java status` as the default Java. If that helper is missing, they log a skip. thinkorswim is installed per user from Schwab's installer into `~/thinkorswim`, and that step is skipped when `~/thinkorswim/thinkorswim` already exists. `--dry-run` prints these commands and does not install them. The lib32 GPU driver packages are selected at runtime for the detected GPU, so their individual package names are not fixed in the scripts. VLC is optional and its install command is commented out.

[`post-install-omarchy-generic.sh`](./post-install-omarchy-generic.sh) is the hardware-agnostic baseline. Use it for any other Omarchy system, and when you want only the shared steps. It installs every entry in the table above except `nvidia-prime`, and it drops `obsidian`. It does not update firmware, disable a touchscreen, mount a data drive, or set a Steam library path, a monitor, a scale, or a hostname.

## Removed packages

Omarchy installs these by default. The post-install scripts remove them after `omarchy update`. `omarchy pkg drop` removes a name only when it is installed (`sudo pacman -Rns --noconfirm`). `--dry-run` prints that command and does not remove the package. `omarchy update` may not install them again; the drop still runs on every post-install.
